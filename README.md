# Taskflow Backend

## Proje Tanımı
Taskflow Backend, görev yönetimi için Node.js kullanılarak geliştirilmiş bir backend uygulamasıdır. CRUD işlemleriyle görev ekleme, silme, güncelleme ve listeleme yapılabilir. Testler Postman üzerinden gerçekleştirilmiştir.

## Kullanılan Teknolojiler
- Node.js (HTTP modülü)
- Postman (API testleri)
- Git & GitHub (versiyon kontrol)
